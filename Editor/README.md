# Data Editor 사용법

## 1. 실행 방법 (중요)

File System Access API는 **보안 컨텍스트(https 또는 localhost)** 에서만 동작합니다.
`index.html`을 더블클릭해서 `file://`로 여는 방식은 **작동하지 않을 수 있습니다.**
반드시 로컬 서버로 열어주세요.

```bash
# admin 폴더를 프로젝트 루트(Portfolio/) 옆이나 안쪽 어디에 두고, 그 폴더에서:
cd admin
python3 -m http.server 5500
# 브라우저에서 http://localhost:5500 접속
```

또는 VS Code의 "Live Server" 확장을 사용해도 됩니다.

브라우저는 **Chrome 또는 Edge**를 사용하세요. (Safari/Firefox는 File System Access API 미지원)

## 2. 폴더 열기

**📁 데이터 폴더 열기** 버튼을 누르고 프로젝트의 아래 위치 중 하나를 선택하세요:
- 프로젝트 루트 폴더 (내부에서 `js/data/*.json`을 자동으로 찾습니다)
- 또는 `js/data` 폴더를 직접 선택

찾는 파일: `zones.json`, `events.json`, `resume-data.json`, `ui-text.json`

처음 폴더를 선택하면 브라우저가 "이 폴더에 대한 접근을 허용할까요?" 팝업을 띄웁니다 → 허용.

## 3. 편집

- 왼쪽 탭: World(zones/events) / Resume(포트폴리오/자격증/이력/스킬) / UI 텍스트
- 가운데 목록에서 항목 선택 → 오른쪽에서 편집
- 순서가 의미 있는 데이터(zones, 자격증 등)는 목록의 ▲▼ 버튼으로 순서 변경 가능
- `scenery`, `items`(skills)처럼 구조가 복잡한 값은 raw JSON 텍스트로 직접 편집

## 4. AI 번역 (무료, MyMemory API)

- 각 다국어 필드(한/영/일)의 EN, JA 칸 위 **⚡ 번역** 버튼 → 해당 언어만 번역
- 항목 상단 **⚡ 빈 칸 전체 번역** → 비어있는 EN/JA만 한 번에 채움 (이미 채워진 값은 건드리지 않음)
- 긴 텍스트(About 소개글 등)는 자동으로 문장 단위로 나눠서 번역 후 합칩니다.
- **주의**: 무료 API라 품질이 완벽하지 않습니다. 특히 학교명, 기관명, 고유명사는
  반드시 직접 검수 후 저장하세요. 번역은 초안일 뿐, 자동 저장되지 않고
  텍스트 칸에만 채워지므로 항상 수정 가능합니다.

## 5. 저장

- 각 탭 상단의 **💾 [파일명] 저장** 버튼을 눌러야 실제 디스크에 반영됩니다.
- 저장하지 않은 변경사항이 있으면 왼쪽 탭에 노란 점(●)이 표시됩니다.
- 파일별로 개별 저장되므로, 여러 탭을 수정했다면 각 탭에서 각각 저장해야 합니다.

## 6. 제한사항

- 브라우저를 새로고침하면 폴더 접근 핸들이 초기화되어 다시 "폴더 열기"를 해야 합니다
  (파일 내용은 저장 시 디스크에 반영되므로 데이터 손실은 없습니다).
- 이미지 업로드 기능은 없습니다. `image` 경로는 텍스트로만 입력합니다.
- 여러 사람이 동시에 같은 파일을 열어 편집하는 것은 지원하지 않습니다(마지막 저장이 우선).
